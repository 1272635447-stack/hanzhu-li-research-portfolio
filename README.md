# Hanzhu Li — Research Portfolio

This repository brings together independent research and methods projects at the intersection of **Human-Centred AI, evidence evaluation, and AI-supported learning**.

## Projects

1. **[AI-generated research-claim audit](projects/01-claim-audit/README.md)** — a researcher-led audit of 40 claims across five AI-generated research cards, checked against cited source papers. The review recorded method-description misdescriptions, terminology shifts, and omitted qualifications; these observations were not treated as quantified error categories.
2. **[Human–AI evidence-evaluation prototype](projects/02-evidence-evaluation-prototype/README.md)** — an offline A/B/C interface artifact for inspecting claim–evidence relationships. A provides source access/search; B supplies an evidence passage; C presents the same evidence with structured checking prompts.
3. **[Psychometric methods training](projects/03-psychometric-methods/README.md)** — an R-based methods exercise using a synthetic 300-record, 15-item questionnaire dataset to practise reliability analysis, EFA, CFA, and discriminant-validity diagnostics.

## Research integrity and scope

The claim audit was a researcher-led, single-reviewer exercise. It was not a study of students, was not designed to estimate the prevalence or rate of AI errors, and should not be presented as independent expert consensus or independent blind review. Any retrospective AI-assisted reconstruction is identified as such.

The claim–evidence materials cover 12 cases and 23 subclaims. Four provisional substantive judgement categories are used: Supported, Supported with caveat, Contradicted, and Not established. **Pending** is a workflow status for cases where the evidence or adjudication is not yet sufficient to settle a judgement; it is not a fifth substantive category. These categories have not been validated as a student assessment or psychometric scale.

The psychometric project uses **simulated data**, not student responses, and does not constitute empirical validation of the questionnaire. The evidence-evaluation prototype is an **offline demonstration**; it does not call a live language model and has not been tested with human participants. Technical checks of the artifact do not establish improvements in human judgement, verification behaviour, trust calibration, or learning outcomes.

The public repository contains selected project documentation and reviewed source materials. Researcher-only answer keys, restricted prototype builds, and full source-evidence workbooks are excluded pending separate release review.
